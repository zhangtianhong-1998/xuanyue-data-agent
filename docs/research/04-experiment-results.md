## 2. 关键观察

**贡献可以超过 100%，也可以为负。** 合成销售数据总额 3000 → 2600，东区 -700、西区 +300，净变化 -400。相对净变化的贡献为 175% / -75%。把每组贡献强制限定在 0–100%，会掩盖抵消关系。总量不变的另一个样例仍有 -700 / +700 的结构变化。

**恢复会重跑节点，外部作用需要自己的去重机制。** 实验在报告已写入独立账本、节点尚未返回时以退出码 73 中断。恢复后报告节点尝试了两次，账本只有一份报告，来自我们定义的唯一键。不是所有外部系统都有相同能力；正式工具应逐个设计幂等或核对步骤。

**协议接通不代表结果合同成立。** MCP 第一次运行返回裸 dict 的状态工具没有提供客户端预期的结构化对象，检查中止。明确返回模型和错误检查后完成。失败输入、结果与脚本保留在 [失败记录目录](../../research/spikes/mcp-local-contract/failures/)。
