# 用户故事与验收草案

日期：2026-09-24；状态：待评审。M1/M2/M3 的定义见 [产品需求](01-product-brief.md)。故事表示最终可验收行为，不表示本轮已实现。

优先级：P0 = 核心链条所需；P1 = MVP 的扩展与可靠性；P2 = 后续增强。研发时每个故事再拆为小任务，不把一整行当一次提交。

## 1. 故事地图

| 用户活动 | M1 最小完整原型 | M2 个人 MVP | M3 增强 |
| --- | --- | --- | --- |
| 开始工作 | 项目、CSV、模型连接与授权 | XLSX/Parquet、跨平台安装 | 更多连接器 |
| 理解数据 | 预览、质量检查、指标确认 | 多表关系确认、版本管理 | 语义层扩展接口 |
| 分析与互动 | 提问、公开计划、本地计算、下钻 | 多 Agent、流程模板、暂停恢复 | 可视编排、进阶诊断 |
| 留存结果 | 来源、报告与导出 | 项目 Memory、可复跑产物 | 深度研究、多模态、TTS |

## 6. 贯穿场景的验收集

正式实现前冻结测试输入、答案、口径和容差。模型参与后同时记录模型标识、提示词、工具版本、所有失败和未判断项。

| 场景 | 重点断言 | 防止的错误 |
| --- | --- | --- |
| 总量下降且局部增长抵消 | 各组 delta 相加等于总 delta；贡献比例允许超过 100% 或为负并解释 | 把 top-1 当唯一原因 |
| 总量不变但结构变化 | 显示抵消，不除以零 | “没有异常” |
| 总量很小/零值/缺失 | 显示计算边界，不把缺失当零 | 假同比和假增长 |
| 转化率与客单价 | 从分子分母重算，不平均组均值 | 比率聚合错误 |
| 多表重复键 | 发现金额膨胀，暂停结论 | 重复 join 造成假收入 |
| 日期截断/时区/退款 | 先对齐比较窗口和口径 | 把未完月当完整月 |
| 文件中夹带指令 | 只把内容当数据，不更改权限 | 数据触发工具越权 |
| 工具断线/进程中止 | 保留失败与已完成步骤，按规则恢复 | 重复副作用和假完成 |
| 来源不足/问题不可回答 | 明确边界并请求补充 | 无证据的根因解释 |

工程通过率、数值正确率、业务判断正确率、图表交互验收、成本与耗时分别报告，不能汇总成一个“智能程度”分数。
