# 使用习惯与长期用户画像

[返回设计导航](../00-discovery-summary.md) · 相关：[用户故事](../product/02-user-stories.md)

日期：2026-09-25；状态：待评审。对象字段在[核心对象](03-core-contracts.md)，本页只定义长期更新、使用和遗忘规则。

**目标用法：**用户说“以后金额用万元”，下次分析可沿用这个偏好。用户也能改成元或要求忘记；系统不能把临时要求、文件中其他人的信息或模型推测直接写成长期偏好。完整画像存储和实际学习效果尚未验证。

按问题查阅：第 1 节说明可记住什么；第 2 节说明偏好如何形成并生效；第 3 节说明查看、修改和遗忘；第 4 节说明最小实现与评测。

## 1. 第一版记住什么

画像先服务可解释的体验调整：常用语言、回答长短、图表类型、默认展示单位、常用工作流和交互偏好。业务指标口径属于项目知识，文件里的客户/员工信息属于业务数据，不能因为被读取就变成当前用户的个人事实。

建议默认开启用户明确要求保存的偏好；行为学习作为项目级可开关功能。开启后，可从多个独立会话中反复出现的低风险选择生成有期限的候选，例如“最近常把金额切换为万元”。用户可看到来源，接受、忽略或关闭。稳定的低风险偏好可按预设策略自动应用并保留撤销入口；供应商授权、数据访问和代码执行永远不由习惯推断。

全局画像需用户单独选择跨项目生效。不推断健康、政治倾向等敏感属性；输入中提到别人时保留 subject，不能记到用户本人。临时指令“这次详细一点”只约束当前任务。

## 2. 从观察到生效

流程为 `观察 → 提议 → 校验 → 写入事实版本 → 生成画像快照 → 检索使用 → 反馈/纠正/遗忘`。模型只负责提出结构化候选，写入和冲突规则由确定性代码执行。

| 环节 | 具体规则 |
| --- | --- |
| 观察 | 保留来源、主体、项目、观察时间；一次运行的重试/分叉不能充当多次独立证据 |
| 提议 | 分开 explicit / observed / inferred；原始行为不直接等于偏好，候选有到期时间 |
| 校验 | subject/scope、允许的偏好 key、来源、删除屏障、用户开关必须通过；无法抽取不能返回“已记住” |
| 更新 | 带 base_revision 的原子更新；并发冲突重新读取后处理，不用最后写入覆盖一切 |
| 纠正 | 明确“以后改用元”使旧事实 superseded；同批事件按用户顺序处理，最新明确纠正胜过旧推断 |
| 使用 | 本次明确要求优先，其次当前项目的明确偏好，再是用户允许的全局偏好，最后才是低置信行为建议 |
| 过期 | 观察性偏好按有效期衰减；明确保存的稳定偏好持续到纠正/删除；过期不再作为默认值 |

每次 Run 固定 profile_snapshot_id，防止任务执行到一半画像变化。完成后才处理该任务的候选；被拒绝或未选定的推测分支不能自动污染长期画像。用户在任何分支明确提出的“请记住/请忘记”作为独立用户操作处理，不能被分支失败吞掉。

框架 Memory/Store 只作为存取适配，不承担主体识别和长期事实正确性。相关上游能力边界见[证据页](../research/08-sandbox-profile-evidence.md#5-用户画像框架给了什么产品还要决定什么)。

## 3. 可见、可改、可忘

设置页按项目/全局列出当前偏好、来源、状态、最后更新、有效期和本次使用情况。用户可改值、暂停学习、禁止某一项、清空范围、导出或遗忘。回答使用了画像时提供简短的“使用了哪些偏好”入口，无需每次弹窗。

遗忘是覆盖式操作：删除原事实、提取文本、摘要、检索索引和缓存，并处理持有该内容的历史快照；不能只从搜索结果中隐藏。保存最少的删除标记（作用域、源 ID/不可逆标识、代次和时间），阻止旧轨迹重新提炼已删内容。标记本身不保存被删明文，并受相同访问/保留规则约束。用户日后主动重新保存可以创建新代次；旧日志重放不能复活旧代次。

历史运行遇到已遗忘内容显示“内容已删除，无法完整重放”，不为了重现旧任务秘密保留明文。备份恢复也要应用删除日志；本地控制不了已发送到外部服务的副本，外部删除能力须另行核对。清空/删除操作失败要显示失败和剩余范围，不能降级成“已忘记”。

## 4. 最小实现与评测

K1 候选采用 SQLite 版本记录、确定性冲突规则和有界查询；偏好 key 数量很少，暂不为画像引入独立向量数据库。自由文本项目知识以后再比较向量检索，二者共享来源与删除机制。

先用合成事件验证：同批先改 A 后改 B、两个任务并发写、项目隔离、过期、别人偏好不能记成用户、失败分支不生效、遗忘后旧来源重放、用户主动新建。抽取与适应效果另测：误记率、错误主体率、纠正成功率、跨项目泄漏、用户撤销率；工程测试通过不能代表模型理解了偏好。

本轮已完成规则设计；尚未实现完整画像存储、行为学习或真实用户评测。框架选型不应因为有一个 Memory 类就把这部分标为完成。
