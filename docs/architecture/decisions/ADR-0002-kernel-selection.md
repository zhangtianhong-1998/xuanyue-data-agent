# ADR-0002：内核优先，LangGraph 作为调度候选

- 日期：2026-09-25。
- 状态：**Proposed，待用户评审**。
- 对应：US-011、026–028、034–042。
- 替代：ADR-0001 中关于 Agent 路线和研发先后的旧提案。

问题：用户需要编排混合流程、持久恢复、历史节点分叉和多 Agent 协作，单纯从经营分析场景推选完整技术栈不足以支撑决定。

建议：用 LangGraph 承担 K1 可恢复调度；产品持有核心对象、授权/预算、事件、画像、产物和副作用协议。AgentScope 作为子执行器候选，并保留为未来完整编排器备选；不自建通用执行器。新增的跨内核需求见 [ADR-0003](ADR-0003-runtime-interoperability.md)，旧提案“不同时接入”的限制已撤回。

完整比较、代价和退出条件只在[内核选型](../02-kernel-selection.md)维护；验证范围见[对照实验](../../research/09-framework-comparison.md)。后续真实模型、子图回溯、取消、沙盒和跨平台发行仍需验收。

评审记录：待用户确认、修改或拒绝。文档提交/公开发布不代表架构提案获批准。
