# 手写执行器对照

本实验只依赖 Python 标准库，建议使用 Python 3.12，与另外两项比较保持一致。运行：`python3 run.py`，或使用本机的 `uv run --python 3.12 --no-project run.py`。

实现同一份 `../scenario-v1.json` 的 F01–F08：自写 SQLite 状态、检查点、事件表、线程分支、进程恢复和副作用账本。没有第三方 Agent 框架依赖，所以无第三方依赖锁文件；结果记录实际解释器、系统、场景与脚本哈希。

此实现用来显露需要自己维护的机制，不是可复用的完整 Agent 内核。固定图能通过用例不代表可正确运行任意用户工作流；动态编译、取消、流式模型、权限恢复、迁移、多实例竞争和沙盒都没有实现。所有通过项归类为 `application_custom`。

复核增加非法路由的持久错误事件断言，当前 results.json 对应当前脚本；之前的脚本与结果保留在 history/attempt-01，仅作代码快照，不在该子目录直接执行。分叉读取 before_parallel 快照后仍重算固定 transform 依赖，并非任意位置的通用恢复编译器。
